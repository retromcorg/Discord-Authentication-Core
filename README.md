# Discord Authentication Core

An extension for DiscordCore-6 that links Discord and Minecraft accounts on Project Poseidon V2 servers.

## Requirements

- Project Poseidon V2
- Java 25
- DiscordCore-6 1.0.0 or newer

Version 1.2.0 and newer target Poseidon V2 and are not compatible with Poseidon V1. Existing `config.yml`
and `data.yml` files remain compatible with the V2 port.
